# جمعية الأمل — مبادرة تعاونية مقترحة

هذه الصفحة تعرض تصورًا أوليًا لمبادرة تأسيس جمعية تعاونية تبدأ بمشروع سوبر ماركت مملوك للأعضاء.

## تنبيه قانوني ومالي
- المبادرة غير مسجلة حاليًا ولا توجد عضوية رسمية أو اكتتاب أو تحصيل أموال.
- مبلغ 10,000 جنيه لكل عضو، واستهداف 100 عضو، أرقام افتراضية للنقاش وليست طلبًا للدفع.
- لا توجد أرباح أو عوائد مضمونة. المشروع التجاري قد يربح أو يخسر.
- أي تأسيس أو مساهمات مستقبلية مشروطة بتحديد الشكل القانوني المصري الصحيح، واعتماد النظام الأساسي، ومراجعة محامٍ ومحاسب وجهة تعاونية مختصة.
- لا تجمع الصفحة بيانات شخصية أو بنكية.

## التصور
- مشروع البداية المقترح: سوبر ماركت.
- إدارة تنفيذية ينتخبها الأعضاء وفق النظام الأساسي والقانون.
- رواتب العاملين منفصلة عن أي توزيع للفائض.
- يُدرس تكوين احتياطي والتوسع، ثم توزيع الجزء المعتمد من الفائض بالتساوي إذا أجاز القانون والنظام الأساسي ذلك.
