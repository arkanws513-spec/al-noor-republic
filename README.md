# جمعية النور التعاونية | Al-Noor Cooperative

مبادرة تعاونية قيد التنظيم تهدف إلى جمع الأعضاء حول تأسيس وتشغيل مشروعات مشتركة، مع المشاركة في القرار والشفافية المالية والإدارة المسؤولة.

## الفكرة الحالية
- التصور المبدئي لمساهمة العضو: **10,000 جنيه مصري**.
- تجميع رأس المال لتأسيس مشروع أو مشروعات يوافق عليها الأعضاء بعد دراسة الجدوى.
- لا توجد أرباح مضمونة، وقد يتعرض رأس المال للخسارة.
- لا يتم جمع أي أموال قبل تحديد الشكل القانوني المناسب في مصر، واستكمال العقود واللوائح والضوابط المالية والإعلان عنها بوضوح.
- هذه المبادرة ليست إعلان اكتتاب أو عرضًا استثماريًا، ولا يُطلب من الزوار إرسال أموال.

## تنبيه
المحتوى تعريفي وتصوري، وليس استشارة قانونية أو مالية. يجب مراجعة مختصين في مصر لتحديد الشكل القانوني والالتزامات قبل بدء النشاط أو قبول مساهمات.
